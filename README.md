# Trabajo-de-grado
Compilacion de los codigos implementados en el prototipo de la estacion meteorologica
El presente proyecto consiste en el diseño, construcción y puesta en marcha de un prototipo de estación meteorológica haciendo uso de tecnologías IoT, capaz de monitorear variables ambientales y de calidad del aire. Funciona con dos protocolos de comunicación (LoRa y WiFi). El desarrollo del proyecto consta de dos etapas: la primera abarca el diseño del sistema electrónico y la selección de las variables a medir; la segunda consiste en una serie de pruebas en las que se analizará el desempeño del sistema en condiciones reales, con el fin de realizar posibles mejoras para una futura expansión hacia una red de estaciones meteorológicas en todo el municipio. El prototipo fue probado en condiciones reales en la terraza de la alcaldía de Tuluá, donde se encuentra instalado actualmente. Los datos obtenidos se visualizaron en la plataforma Marso Smart Cities, permitiendo el acceso y análisis desde cualquier dispositivo con conexión a internet. Se exploraron distintas opciones tecnológicas y protocolos de comunicación. Finalmente, se destaca que el proyecto satisface con éxito la necesidad de transmitir los datos medidos por los sensores. Este prototipo proporciona una base sólida para una futura red de estaciones meteorológicas, incentivando la innovación e impulsando al municipio hacia su transformación en una ciudad inteligente.
